- If any card in the game mentions Loot, shuffle the Loot cards face down to make a Loot pile beside the Supply. [official]
- "Gain a Loot" means gain the top card of the Loot pile. If it runs out, no more Loot can be gained. [official]
- The Loot pile isn't in the Supply, so it doesn't count for game end, and "a card costing up to" effects can't gain from it.
- Every Loot is a Treasure that costs {cost:7}, so it counts for effects that look at Treasure costs.
